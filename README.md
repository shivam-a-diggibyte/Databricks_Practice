# Databricks Lakeflow Spark Declarative Pipelines

## Overview

This repository contains hands-on practice with Databricks Lakeflow Spark Declarative Pipelines using Python and PySpark. It covers data ingestion, transformations, data quality, Medallion Architecture, pipeline dependencies, and workflow orchestration.

## Repository Structure

```text
Databricks_Practice/
├── README.md
└── src/
    ├── lab1_basic_pipeline.py
    ├── dependencies.py
    └── medallion_pipeline_using_sdp.py
```

## Technologies

* Databricks Free Edition
* Python and PySpark
* Lakeflow Spark Declarative Pipelines
* Apache Spark
* Git and GitHub

## Key Topics

* Streaming tables and materialized views
* Incremental data processing
* Pipeline dependencies
* Bronze, Silver, and Gold layers
* Data quality expectations
* Workflow orchestration using Databricks Jobs
